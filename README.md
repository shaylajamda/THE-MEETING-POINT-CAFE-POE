Form Functionality 

The website includes a contact form that allows users to make reservations, provide feedback, send general enquiries and arrange appointments. 

The form uses client-side JavaScript validation to check the information entered before processing the submission. The validation checks that the user has entered a name, valid email address, valid South African contact number, request type and message. 

If invalid information is entered, clear error messages are displayed to inform the user what needs to be corrected. 

The website is a front-end academic project and does not currently use a server-side database or backend. Therefore, form information is not permanently stored or sent to a real business. JavaScript is used to provide a simulated submission experience and display a relevant response to the user without refreshing the page. 

If the website were developed as a live business website, AJAX could be used to send the validated form data to a secure backend or form-processing service without requiring the page to refresh.
